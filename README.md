# 교육훈련이력카드 문서 자동화

공유 캘린더 **유로인사이트**의 교육 일정과, 직원이 승인한 Gmail에서
**제목이 정확히 일치하는 메일**을 바탕으로 직원별 교육훈련이력카드를 작성하는 프로젝트입니다.

## 합의한 동작

- 매월 첫째 월요일에 지난달 교육 이력을 정리합니다. 시간대는 Asia/Seoul입니다.
- 개인 캘린더가 아닌 지정 공유 캘린더만 사용합니다.
- 일정 제목으로 교육 후보를 판단하고, 메일 제목은 부분 검색 후에도 원문과 정확히 비교합니다.
  `Re:`/`Fwd:` 제거 등 제목 보정은 기본적으로 하지 않습니다.
- 교육명·교육 날짜·시간·장소·비고를 기록합니다.
- 직원별 참가자를 구분하고, 안내·참석·수료를 구분합니다. 미확인 정보는 추측하지 않습니다.
- 직원별 폴더에 `(YYYY-MM-DD)UIT-F601-03_교육훈련이력카드.docx`로 저장합니다.
- 완성된 파일은 채팅 링크와 지정된 담당자 메일 첨부로 전달하는 것이 목표입니다.
- 다른 직원 Gmail은 Google OAuth 승인 후 연결하고, 분기마다 동의를 갱신합니다.

## 현재 상태

이 저장소는 대화에 기록된 작업을 복구한 개발 초안입니다.
OAuth 연결 서비스는 **미배포**이고, 기존 월간 자동화와도 아직 연결되지 않았습니다.
Google Cloud 앱 등록, HTTPS 배포, Gmail/캘린더 조회 작업 및 월간 실행 통합이 필요합니다.
아래 코드가 저장되었다고 다른 직원의 메일을 읽을 수 있게 되는 것은 아닙니다.

기존 Codex 예약은 이 GitHub 저장소와 별개입니다.
실제 예약 설정은 이 저장소에 포함되지 않습니다. 배포 시 운영자가 실행 주기를 확인해야 합니다.

## 파일

- `mail_access.py`: 초대 → Google 승인 → 암호화된 토큰 저장의 개발 초안
- `document.py`: 제공된 DOCX 양식에 확인된 교육 이력 입력
- `SETUP.md`: 실행/배포와 남은 작업
- `requirements.txt`: 의존성

공개 저장소에는 직원 메일, 작성된 개인별 카드, 원본 양식, OAuth 비밀정보를 넣지 않습니다.
원본 DOCX 양식은 별도 비공개 저장소/파일 보관함에서 제공해야 합니다.
전체 채팅 원문이나 실제 메일함 데이터는 이 저장소에 포함되지 않습니다.
